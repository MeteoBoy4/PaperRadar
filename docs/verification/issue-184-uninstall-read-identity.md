# 卸载预检读取身份的独立回归

依据：[所有者降范围裁决](https://github.com/MeteoBoy4/PaperRadar/issues/177#issuecomment-6814413453)、ADR-0068，以及所有者回报的聚合预检 `file_changed`、三个 `deployment_lock_unavailable` 和 `host_tool_identity`。

## 原因与边界

旧工具比较完整 `stat`。冷文件或空锁的读取会更新访问时间 atime，因此检查本身即可触发误拒绝；工具/锁分支又把该原因合并成泛化错误。合成冷文件、空锁与完整卸载路径的五项修前回归失败；现场只读对照显示工具解析路径及 SHA 与原清单一致。

读取改为无跟链、非阻塞、close-on-exec 的单个文件描述符；读取前后对照路径与 fd 的 dev/inode、完整 mode、uid/gid、nlink、size、纳秒 mtime/ctime。只排除读取副作用 atime，不忽略安全身份或内容变更。锁 fd 另绑定读取前身份，仍要求真实排他锁；真实竞争报告 `deployment_lock_busy`，身份错误保留固定原因，I/O 不可用独立报告。工具摘要规则不变。

## 证明限制

修复只涉及独立卸载工具，不改变产品豁免、隔离、准入源码守卫或 frozen contracts。未修改数据库表或 migration，未访问用户业务数据库。
真实主部署与九份候选已由普通所有者身份只读重新认证，派生审阅 JSON 与上轮原字节相同；这不代替 root 专属检查或现场卸载后验。新的工具字节及命令须由所有者本人审阅执行，旧工具／候选原字节保留；不构建新封印包、不加载 AppArmor、不写 journal。
完整离线门禁未运行，现场卸载尚待所有者动作。
