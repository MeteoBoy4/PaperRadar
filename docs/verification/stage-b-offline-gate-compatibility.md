# B 离线门禁兼容修复：独立 D1

本台账只登记本次修复的新增离线覆盖，不改写既有 B 的 65 模块 / 637 节点历史台账，
也不扩大正式固定范围的 285 模块 / 5281 节点。开发子集与兼容组合不替代最终冻结树的完整门禁。

## 修复范围

- `paper show/trace` 默认保留论文事实的原有输出；显式 `--workflow` 增加完整工作流，
  `--snapshot` 同时启用组合并核对当前性。工作流仍根中性，组件的 14 类受控查询错误
  由组合边界保留原原因并转换为安全 CLI 退出 1。论文事实层不直接导入任务执行模块。
- 运行日志独立白名单只追加 `ambiguous_failure`、`visibility_denied` 两枚已有封闭原因；
  未知值、URL 和原始载荷的拒绝保持。
- 静态预检详细输出的第一个 `check=` 头使用实际检查名，分别披露 Screening 与 Read；
  后续完整未评估片段及披露项 `required=False` 保持，不增加任何准入或豁免。
- 既有 D1 的活文档显式清单补齐 `exposure-export.md`、`reports.md`；共享 DAG 的独立预期
  在 A6 source 尾部补齐 `paper_trace.py`、`stage_b_trace_support.py`。固定成员数、41 条 refs、
  原迁移证明与中央成员集合不变，不从生产集合推导预期。
