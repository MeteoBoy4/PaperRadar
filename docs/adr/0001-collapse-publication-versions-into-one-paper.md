# 将同一学术工作的不同版本合并为一篇论文

状态：决策记录（原文未单列接受状态）；日期：原文未单列；依据：[基线裁决原文](https://github.com/MeteoBoy4/PaperRadar/blob/91e5d02e199f1921ca8afd2b7bdb8f257e6264f3/docs/adr/0001-collapse-publication-versions-into-one-paper.md)；补充／部分取代：无另列关系；正文边界继续适用。

PaperRadar 将预印本和后来发表的正式期刊版本视为同一篇论文，而不为每个版本建立独立论文记录；正式期刊版本出现后，它优先成为论文的当前版本。当前版本的书目信息、全文和活动参考文献代表论文的当前事实，正文变化会使旧分析退出当前结果并产生新的待精读任务。这样可以避免同一工作的重复筛选和重复展示，符合用户以正式发表结果为准的阅读方式；旧版本的来源材料、全文、参考文献观察和既有分析仍作为历史依据保留，版本变化不得静默抹除它们。
