# 允许在已揭晓的校准标签上重算

若初始 32 篇盲评的 80% 精确率或 90% 防漏判门槛失败，PaperRadar 第一版允许根据揭晓结果调整 Screening 配置，并复用同一组人工标签重新产生建议和计算门槛；不强制再收集一组新的 32 篇留出样本。每轮重算必须只追加保存 runtime plan、Screening 制品、指标分子分母和前后关系，并在门禁、报告和最终验收中标记 `reused_revealed_labels`。该结果只能说明调整后的系统贴合这组已经参与调优的人工判断，不得称为新论文上的独立验证；第一版接受这一较弱证据，以控制个人用户的额外盲评成本，未来仍可用新样本另做独立校准。
