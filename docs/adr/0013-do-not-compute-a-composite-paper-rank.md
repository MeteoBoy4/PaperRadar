# 不计算论文综合 Rank

PaperRadar 第一版不采集被引次数，不评价紧急性，也不把研究价值、复用可行性、期刊信誉或重复发现次数加权成综合 Rank。不能归入两条评分队列的人工 accepted 先按决定时间 FIFO 消耗自动名额；随后可转化成果与认知增益在剩余名额足够时各保留一个，其他名额每领取一篇后重新计算二维帕累托前沿。破同时先比较完整等待月数，只有两项分数、价值类型集合和完整等待月数都相同才使用期刊信誉，最后按发现时间。未获名额的 accepted 论文跨日保留资格，但不设防饥饿席位，也不承诺最终获选；用户仍可显式请求不占自动名额的精读。这个选择接受尾部长期积压，以维持优胜劣汰且不伪装成公平队列。
