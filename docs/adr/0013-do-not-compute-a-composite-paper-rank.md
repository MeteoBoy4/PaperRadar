# 不计算论文综合 Rank

PaperRadar 第一版不采集被引次数，不评价紧急性，也不把研究价值、复用可行性、期刊信誉或重复发现次数加权成一个综合 Rank。研究价值与复用可行性作为并列维度决定可转化成果和认知增益两条队列；两条队列都非空时各保留至少一个自动精读名额，剩余候选以两个维度的帕累托关系比较，再优先等待更久者。只有两项分数、价值类型集合和等待时间均相同时才使用期刊信誉，最后按发现时间；低研究价值但高复用可行性进入 pending，而高研究价值但难复用仍是认知增益。每天三个名额只约束当日系统主动领取，未获名额的 accepted 论文跨日积压并继续参与选择；用户显式精读请求不占自动名额。这个选择放弃一个便于排序的单值，但避免来源声望或容易复用掩盖真正研究价值。
