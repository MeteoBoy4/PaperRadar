# 只永久保存产生事实或冲突证据的外部响应

状态：决策记录（原文未单列接受状态）；日期：原文未单列；依据：[基线裁决原文](https://github.com/MeteoBoy4/PaperRadar/blob/91e5d02e199f1921ca8afd2b7bdb8f257e6264f3/docs/adr/0009-retain-only-material-provider-responses.md)；补充／部分取代：无另列关系；正文边界继续适用。

PaperRadar 对实际贡献元数据、参考文献或字段冲突证据的外部成功响应建立内容寻址的不可变来源快照，相同响应体只保存一次。`304 Not Modified`、重复空响应、限流和失败请求只记录结构化执行结果，不永久复制其响应体；规范化事实仍指向支持它的快照。这样保留可追溯和重新仲裁所需的来源材料，同时避免把普通 HTTP 历史和重复错误页面扩张成永久领域数据。代价是无法逐字回放每次失败请求，但失败类别、时间、查询键和重试状态仍可审计。
