# 不自动切换到未经校准的筛选模型

PaperRadar 第一版为 Screening Agent 和 Read Agent 各配置一个主模型，调用失败时有限重试并留待以后恢复，不自动跨模型或跨供应商 fallback。筛选校准记录精确绑定模型、提示词、Profile、输出契约和规则组合；自动换用另一模型会绕过用户对校准相关变更的判断，因此禁止 fallback。用户显式更换 Screening 模型或关键契约时，系统先暂停自动精读并要求把该变化附理由分为 minor 或 major：minor 可以继承门禁但必须重算受影响制品，major 关闭门禁直到重算或新校准通过。PydanticAI 继续隔离供应商接口，以便以后显式切换，但可恢复延迟优先于静默使用另一模型。
