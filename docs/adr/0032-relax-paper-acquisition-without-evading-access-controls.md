# 放宽论文获取方式但禁止访问控制规避

状态：决策记录（原文未单列接受状态）；日期：原文未单列；依据：[基线裁决原文](https://github.com/MeteoBoy4/PaperRadar/blob/91e5d02e199f1921ca8afd2b7bdb8f257e6264f3/docs/adr/0032-relax-paper-acquisition-without-evading-access-controls.md)；补充／部分取代：见本行关系回链；正文边界继续适用。 关系回链：本记录补充／部分取代 [ADR-0012](0012-limit-v1-to-a-minimal-provider-chain.md)、[ADR-0024](0024-wiley-oa-fulltext-via-official-tdm-api.md)，具体适用边界见各正文。

PaperRadar 第一版把摘要与全文获取的约束从“只走最少几条无会话通道”改为“正常自动化访问允许、访问控制规避禁止”的两分边界。允许如实标识的正常请求头（`User-Agent`、`Referer`、`Accept` 等，可使用工具自身的默认浏览器 `User-Agent`，但不以伪造或轮换 `User-Agent` 通过限制）、受控浏览器渲染（Playwright 等执行 JavaScript 读取公开页面）、出版者官方 API 与合法申请的 token，以及按站点规则、官方配额与 `robots` 或服务条款设置的频率、超时、退避与重试；摘要与全文位置可按需通过 Crossref、DataCite、Unpaywall、OpenAlex 与合法开放仓储补充。本人合法持有的机构账号、登录会话或订阅权限改为“审慎允许”：默认关闭、用户显式启用、凭据只存文件系统凭证区（0600）、单篇按需、遵守出版方条款、访问依据记为 `licensed`、不批量下载且不分发受限全文。破解或自动求解验证码、伪造浏览器或 TLS 指纹、轮换代理 IP 逃避封禁或限流、绕过付费墙及其他明确的访问控制、未授权批量下载受限全文仍然禁止，并且不因引入渲染通道而放宽：出现验证码或明确的挑战页即记 `access_blocked_403`/`rate_limited` 并进入人工 PDF 队列。

这个划分替换的是“反爬”这一含混标签：判断标准不是用什么工具，而是请求是否试图改变来源对自己身份、权限或频率的判断。渲染公开页面、带官方 token 调用 API、按配额退避都不改变来源的判断，属于正常自动化访问；破解验证码、伪造指纹、轮换代理、对无权内容实施技术绕过则在改变判断，属于规避。付费墙边界因此不再等同于“只取开放获取”：本人订阅权限覆盖的内容属于已授权内容，而绕过访问控制取得同一内容仍然禁止。

获取策略是版本化事实（`acquisition_strategy_version`），随每次取得记录策略版本、访问依据（`open` / `licensed` / `manual`）、请求头类别、通道（普通 HTTP / 渲染 / 官方 API / 仓储）、凭据类别（不存值）、时间、HTTP 结果与配额事实；相同字节仍按 ADR-0009 只保留一次。摘要审计、版权受限全文登记与失败统计按策略分别保留，不把不同策略的结果合并成一个覆盖率，也不用策略调整改写既有审计结论。凭据值不进入版本化配置、SQLite、日志、报告或 fixture。

策略清单与默认启用项是当前默认值，不是永久技术路线上限：四刊真实审计给出缺失、截断与受阻原因后，应在新 Issue 中增删默认启用的策略或通道，至少提升 `acquisition_strategy_version` 并保留旧策略下的历史结果；固定样本选择、既有审计结论与来源可追溯性不受影响。把技术路线固定进单个实施票会阻止这种按证据调整，因此实施票只固定当轮默认值。

代价是明确的：可取得的来源变多，出站请求、限速状态、凭据类别和策略版本都要按来源分别记录，测试需要区分普通 HTTP、渲染、官方 API 与授权通道四类取得事实和失败分类；浏览器渲染引入更重的运行时依赖，因此它是可选启用通道而不是所有来源的默认路径；`licensed` 内容的许可与合理使用边界依赖用户自行确认，系统只保证不外发、不批量、不分发。

本决议部分修正既有表述：ADR-0012 对 OpenAlex 的排除缩减为引用关系、被引次数与排序用途，摘要与全文位置补充现予允许（ADR-0013 的“不计算综合 Rank、不采集被引次数”不变）；ADR-0024 的“用户人工引导的自有会话凭证只是允许边界、第一版只实现 TDM 通道”和“机构订阅仍然禁止”被本文的授权通道取代，其 TDM token 凭证管理、`403` 探测分类与“不绕过访问控制、`403` 不解释为非开放获取、人工 PDF 队列”原则继续适用。编号说明：本决议占用 0032，Issue #100 评论中拟议的 A10「期刊文章类别依据」ADR 顺延使用 0033。
