# 对 Live 准入证据采用人工激活与限期重验

状态：已接受；日期：2026-11-07；依据：所有者本轮 grill-with-docs Q7–Q10 裁决；补充 [ADR-0046](0046-consolidate-pi-readiness-under-live.md)。

固定安装与配置未变不能证明供应商后台行为未变；受控采集成功也不应直接替所有者启用产品执行。Live 的证据接收权威先核验回执来源、完整性和适用性，再由所有者审阅完整脱敏回执并显式激活对应绑定。人工批准不能补齐未测项、覆盖失败或让任意 JSON/Markdown 自证通过。

供应商能力证据的有效期为验证完成后 30 天，人工激活不重新计时。到期阻断受影响的新模型任务；提前重验失败不延长旧证据，也不能覆盖新失败对旧证据适用性的影响。每次调用仍须核验当前绑定与现场隔离条件，已检测到的变化不能等到到期才处理。

首次验收覆盖完整支持范围；后续按证据依赖关系重验受影响部分。复用证据必须有明确适用依据，无法确定影响范围时扩大重验。每轮先冻结案例、请求上限和停止条件，经所有者批准后执行，重验通过后仍须显式激活；不自动增加模型调用，也不沿用历史实验余额。

相比仅在可检测漂移时失效，本方案限制了旧供应商观察的最长使用时间，代价是周期性调用、人工审阅与可能的等待停机。相比每轮全量验收，针对性重验减少重复成本，但要求维护可复核的证据依赖与失效关系。30 天是维护成本与风险之间的取舍，不保证期间供应商行为不变。
