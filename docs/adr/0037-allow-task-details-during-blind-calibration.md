# 盲评期间允许阶段任务明细

状态：已接受；日期：2026-10-30；依据：[#120 最终裁决 D5（用户选择 B）](https://github.com/MeteoBoy4/PaperRadar/issues/120#issuecomment-6520223100)。

盲评隔离限制 Agent 制品的预测、分数、建议、理由与完整载荷，同时允许论文事实和阶段级
任务明细：任务存在性、stage、attempt、失败类别及失败队列归属。这些明细支持排障和
日常管理；若连明细一起隐藏，trace、failures 与运行日志就需要另一套按许可省略字段
机制。用户明确知悉并接受任务明细可能暗示边界与预测的推论，将其排除在盲评禁运范围外。

任务明细可以显示在 trace、失败列表及日志中，paper_id/stage 照常记录。关联完整载荷、
模型原始响应或正文不因此获得展示或落日志许可，隐藏成员的 Agent 内容在诊断分支同样
受限；秘密和 §8.7 的其他禁写项保持原有边界。普通决定与精读请求仍受共享校准可见性
规则控制，calibration review 仍走专门路径。

这一选择有不可撤回的披露代价：已展示的阶段信息不能靠后续隐藏还原成未暴露状态。
保留本记录用于解释为何隐藏内容的论文仍有可见任务，而不将其误修为全面隐藏。
