# 优先保护用户的长期注意力

状态：决策记录（原文未单列接受状态）；日期：原文未单列；依据：[基线裁决原文](https://github.com/MeteoBoy4/PaperRadar/blob/91e5d02e199f1921ca8afd2b7bdb8f257e6264f3/docs/adr/0021-prioritize-attention-sustainability.md)；补充／部分取代：无另列关系；正文边界继续适用。

PaperRadar 判断产品失误的成本顺序为：每日结果过载导致用户放弃系统，高于漏掉真正相关论文；漏判又高于把昂贵全文精读浪费在低价值论文；复核积压的成本最低。这个取舍解释了普通日报五项、自动精读三项、先校准再自动 Read、积压不重复轰炸和尾部 accepted 可以长期等待等约束。周摘要必须披露复核净积压、accepted 未精读积压及最老等待时间、用户决定覆盖率；提高容量或放宽门禁前，要用这些指标证明不会破坏单用户约三十分钟的可持续使用。
