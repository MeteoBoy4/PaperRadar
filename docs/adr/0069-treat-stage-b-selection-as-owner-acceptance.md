# 阶段 B 选样同时表达用户接受，由 Agent 代为落地

状态：已接受；日期：2026-11-12；依据：本轮所有者 grill 裁决（[归档](../../intent/review/stage-b-grill-decisions.md)）。补充 ADR-0036、ADR-0043 的阶段 B 人工决定流程。

## 背景与取舍

B 的样本由用户根据当轮 JGR 题名、完整主摘要和研究判断主动选择。继续要求用户在 Screening 后再次确认接受，会重复收集同一实验意图。所有者选择将接受授权前移到选样时，以减少人工交互；代价是该人工决定并非用户阅读模型结果后作出的判断，不能被解释为对模型建议的认可或盲评标签。

## 决定

仅在 B 受限实验中，用户通过编号或 DOI 选样并说明理由，即对该选定论文／版本表达接受授权。预选与授权先持久保存；Agent 在所需 Screening 成功后，引用真实 Screening 成功与该授权代为追加来源为用户的 accepted 决定，不再次请求接受确认。记录须区分授权者和代执行者，不能把 Agent 自主判断写成用户决定，或伪造用户看过模型输出。

授权不取决于实验建议是否 accepted；非 out_of_scope 且所需阶段成功的样本可按预先授权继续。out_of_scope 仍停止 value 并保留结果，失败、缺少成功依据或质量不合格均不能靠该授权放行；需要换样时仍由用户从候选清单选择并记录原因，新样本取得自己的授权。不得为迁就样本修改 Profile／Prompt、重置预算或绕过逐文档质量。

该授权不等于 PDF 归属与合法性确认，也不等于六项人工版式核查通过。校准、自动 Read、正常生产消费和实验已暴露排除边界保持原规则。实验选样只支持固定单篇的显式执行，不授权扫描自动队列。
