# 将现场隔离与 Pi 实测的剩余准入责任合并到 Live

状态：已接受；日期：2026-11-06；依据：[所有者合并与收口裁决](https://github.com/MeteoBoy4/PaperRadar/issues/166#issuecomment-6683324540)；补充：[ADR-0039](0039-isolate-pi-with-landlock.md)、[ADR-0040](0040-declare-provider-default-sampling.md)。不改变其权限策略、采样语义、事实接收权威或缺证据阻断要求。

现场 cwd/文件/出站/core 隔离与固定 Pi 的模型/协议能力必须在同一执行绑定下共同满足，拆成独立前置模块容易使责任移交被误读为安全验收，或让 Live 等待一个职责已被吸收的模块。

因此由 **Live 统一拥有原 Cwd 与 EXP-2 未完成的探索、必要观测工程、现场补测及产品准入证据接收/失效责任**。Cwd 不再独立交付，保留其节点 ID 供历史引用，按“已取消，职责并入 Live”维护，不标为已完成。Live 只依赖独立工程前置 Pi；B 继续依赖 Live，Live 必须先关闭其吸收的全部适用安全/能力门槛，不能因为移除独立 Cwd 依赖边就放行执行。

实验票可以按所有者接受的有限证据范围关闭；未观察项、未知值、失败历史与未满足的条件不能因此变成 passed。原固定材料保持字节与证明范围，剩余问题只在 Live 的模块范围和前向承接中维护，不继续以独立 EXP-2 项目重复挂账。B 仍负责真实产品入口、实验根、日志、用途与质量消费，并保留 Live 缺项限制；其他模块的既有责任不转移。

代价是 Live 规格必须同时覆盖部署隔离、协议/模型观察与产品事实接收，不能仅做 RPC 能力包装；换取唯一负责完整执行绑定的模块，并避免以“职责转交”代替验收或产生循环/悬空前置。该归并不授予当前 Live/B 完成、正常生产、正式校准、无人值守或任意新模型调用许可。
