# 明确认证基线能力与当前快照的区别

状态：提议，待所有者评审；日期：2026-11-10；依据：[#177 最终裁决 ADR 责任](https://github.com/MeteoBoy4/PaperRadar/issues/177#issuecomment-6768256547)；拟补充 [ADR-0052](0052-version-admission-uses-and-capability-requirements.md)，方案已由 [ADR-0058](0058-allow-bounded-auth-cache-stat-evolution.md)独立记录。

建议将 ADR-0052 的 `auth_cache_baseline` 定义明确为“自受保护批准采集并接收的固定基线以来，当前成员集合与该策略规定的不变量仍相符”。当前采样只是与固定基线比较的材料，不成为新的信任起点，也不延长原证据时点；首次 v2 基线须由受保护批准采集建立，不能把已漂移的旧基线改名或把当前目录自拍提升为可信来源。

此定义补充只澄清能力所证明的关系；允许演进对象、字段和资源布局的取舍由已接受 ADR-0058 唯一规定，此处不另建同义方案。能力核验、接收、证据激活、当前适用性与历史写入观察继续各自成立。代价是读者须区分“当前快照相同”与“固定基线不变量成立”，避免将正常演进或当前可读误解成已证明完整写史。
