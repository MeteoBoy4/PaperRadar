# Read v2 在末次接收时丢弃无效证据条目，受限源内容只告警

状态：已接受；日期：2026-11-04；依据：[#155 评论 2](https://github.com/MeteoBoy4/PaperRadar/issues/155#issuecomment-6631023698)、[评论 5](https://github.com/MeteoBoy4/PaperRadar/issues/155#issuecomment-6632720328)、[评论 7](https://github.com/MeteoBoy4/PaperRadar/issues/155#issuecomment-6633241060)、[#157](https://github.com/MeteoBoy4/PaperRadar/issues/157)；部分取代：[ADR-0010](0010-use-docling-as-the-only-body-parser.md)、[ADR-0025](0025-allow-local-formula-candidates-with-source-review.md) 中合法受限源字符支持关键结论时的硬失败限制；补充 [ADR-0036](0036-isolate-stage-b-read-experiment.md) 的 EXP-7。

Docling 对公式、表格数值和不可靠字符的能力限制，不等于 evidence 指针或源身份非法。把二者一并拒绝会损失可定位但尚未人工核对的结论；首次即丢弃坏指针又会提前结束修正机会。因此 v2 保留首次整份拒绝和第二次修正机会，只有本代第二次接收才按条目降级。合法源块上的解析限制始终保留分析并生成安全警告。报告必须显著标明未核对与丢弃计数，不得把它们展示为已支撑或已核对。

完整原始候选先经过严格 JSON、Schema、全部文本、语言、价值类型及评分检查，之后才检查业务指针。`degrade_policy=final_attempt`，`attempt_ordinal` 是任务层领取时分配的本代接收序号，闭集 `{1,2}`；末次等价于序号 2，与剩余预算及调用方的 retry 意图无关。纯接收器不推断序号、不授予预算。首次指针错误整份拒绝；末次仅丢弃 `main_findings`、`reusable_points`、`key_limitations` 的完整列表项，任一坏引用即整条丢弃，不去重、不修复或保留部分引用。两项评分理由始终整份拒绝；Schema 层空 evidence 与空字符串 ID 同样始终拒绝。丢弃后主要发现和可复用点同时为空，且丢弃前至少一者非空，返回 `output_without_support`，任务层归入既有 `output_invalid`。

上下文、身份、页码、bbox、charspan、源块闭包（包括 `unknown_source`）错误始终属于程序侧错误，消费者必须在领取前检查。公式候选、占位与生成展示内容不成为源或 evidence 目标；模型把它们当 ID 引用时按未知指针处理。只有可回放的父源块可支持公式结论；真实公式父源块覆盖统计和缺口披露由 EXP-6 的正文生产链负责，不能通过给候选造 evidence 锚点绕过。

EXP-7 的身份分为三层：`read-evidence-v2` 是接收依据，包含末次降级策略；`read-numeric-v2` 是数值诊断策略；`read-content-limitation-v1` 是公式、不可靠字符和表格受限数值警告策略。三者都不进入 StageInput 或模型指纹：它们消费模型原始输出，不改变模型输入；警告规则变化可以从保存的候选与上下文重算，不刷新模型预算、不自动重跑。模型可见的 Schema、Prompt、正文呈现或消费配置改变仍按各自指纹语义处理，不能借“警告变化”隐去输入变化。

原始候选、策略、序号、规则身份、确定性丢弃清单与警告随成功分析保留。丢弃记录只含安全字段路径、类别、原条目序号、首个坏指针原因及能解析的源定位，不另存坏 ID 或原文。数值和受限内容诊断只对保留条目计算，位置仍指向原始候选。重放使用完整候选和当时的上下文、策略、序号与规则版本，从零重算丢弃清单逐字段核对；新代从序号 1 重新判断，不能继承旧代降级许可。

选择增量 v2 而非原地修改 A9：v1 源码、包入口、15 个冻结测试模块、固定计数和规则格式保持原字节，v2 自持错误、诊断、常量和结果类型，只读复用冻结的 Context、Schema、解析与数值纯函数。v1 历史分析仍按 v1 接收记录读取；历史失败不追溯制造分析。备份对不受支持的证据版本受控拒绝；不支持历史警告策略时保留已记录警告，不声称与当前规则等价，也不以该差异刷新预算。

代价是同时维护两套判定，须以独立 D1 的共同行为对照与差异矩阵防止漂移。末次仍可能丢弃大量内容或触发全空下限；这是保留修正机会并防止空壳成功占据当前分析位置的取舍。该纯接收决策不证明真实 Docling 保真、科学语义蕴含、现场 Pi 或生产 Read 资格。
