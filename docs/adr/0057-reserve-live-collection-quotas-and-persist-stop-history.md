# 预占 Live 采集额度并持久保存跨计划停止历史

状态：Proposed；依据：[#177 最终裁决 E-1/E-2、S-11](https://github.com/MeteoBoy4/PaperRadar/issues/177#issuecomment-6768256547)、[#178 实施澄清](https://github.com/MeteoBoy4/PaperRadar/issues/178#issuecomment-6768780535)；补充 [ADR-0047](0047-expire-and-explicitly-activate-live-evidence.md) 与 [ADR-0055](0055-separate-protected-admission-ledger-from-business-facts.md)，待所有者评审。

仅在单个批准计划中累计调用，会使换计划、重启或重建 collector 获得新余额。任何失败永久停止又使普通协议或资源故障需要重新批准部署。采集额度必须独立于业务 task/attempt 预算，同时保留安全失败的首次停止和旧回执的不可变性。

Live 使用固定受保护累计域 `live-177`，计划只引用该域，不能自行命名新域。所有者对既有受保护账本执行一次显式兼容 cutover，新增独立采集事实表，保留原计划、回执、来源与事件。root 在每个宿主 auth CLI、独立 network 操作或 Pi prompt 写入前分别原子预占；联网为 auth 与独立 network 之和，最多 40，模型最多 40。预占后即消费，不退款；在真正派发前崩溃或结果未知也消费。不借重启、重部署或恢复旧快照移除尾部事实；谱系不明拒绝。开发工具、所有者操作、loopback 与模型自带 DNS/TLS 不计独立 network；auth CLI 的内部往返不重复计数。这只在 Live 范围取代 #168 P-7，B 的后续授权单独裁决。

v2 轮内首失败即停。每个稳定案例模板保存当前失败原因与连续失败轮数，同原因递增、原因变化从 1 开始；只有该模板通过才清其链，其他模板成功不清零。达到 3 时整个累计域持久停止；安全类首次停止，累计失败 6 轮全局熔断。安全类包括隔离／出站意外放行、未登记凭据变化或 core/report、绑定／模型身份与 WS 漂移、敏感输出、权限异常、账本／来源失信及 interrupted。全局失败轮数和停止事实永不因成功清零。

续跑仍受当前窗口、剩余额度、失败链和熔断约束。相同完整执行绑定下，已通过模板引用原受保护回执，不重跑、不刷新原 verified_at；新轮只执行未通过模板，回执交叉绑定本轮预占、先前来源和开始时历史摘要。接收与证据激活保持所有者独立操作。v1 模型、Schema、字节及计划首失败永久停止语义保留，未知版本拒绝。

代价是增加一份须单独备份、核验和保留谱系的采集日志，以及无法区分「预占后尚未派发」和「结果丢失」时的保守消费。它避免用回执事后自报或 agent 操作纪律代替 root 派发前约束。批准计划与采集回执升级为 v2 不默认推进业务 Alembic migration，也不自动接收、激活或扩大模型／材料范围。
