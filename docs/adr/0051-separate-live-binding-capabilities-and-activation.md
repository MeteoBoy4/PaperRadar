# 分开核验 Live 完整绑定、分项能力与执行资格

状态：已接受；日期：2026-11-08；依据：[#167 H4/H5接收及三条修正](https://github.com/MeteoBoy4/PaperRadar/issues/167#issuecomment-6719042528)；补充 [ADR-0047](0047-expire-and-explicitly-activate-live-evidence.md)。 “产品执行必须凭证据”的约束关系由 [ADR-0068](0068-replace-live-prerequisites-with-explicit-owner-waiver.md) 取代，其他证据与历史规则保留。

有限探索可留下若干已核事实和若干未测或不可判断的能力；用一个总通过值接收它们，会把未测项涂成通过，或丢掉其他项独立成立的事实。Live接收权威必须先核来源、完整性和完整执行绑定；绑定缺项不接收。能力主张分别保存 `verified`、`not_assessed`、`unknown` 及各自依据、范围与原验证时间，不以探索签收或某一项通过替代另一项。历史失败保持，不能借分项状态抹除失败或撤销事实。

能力核验状态与接收、人工激活、到期、撤销和当前适用性分别判定。Live规格须明确每种用途所需的能力集合；所需项均verified、当前适用且在有效期内，并经显式人工激活，才可能取得相应执行资格。无关未测项不能被汇总为已验，也不使独立verified事实消失；有限探索签收不能自行删掉用途的必要条件。完整绑定本身不授执行许可，verified历史事实到期后也不能继续执行。

供应商能力证据仍按ADR-0047自原验证完成起30天硬到期。接收、H4/H5签收和人工激活均不重新计时；到期时尚未激活的证据须先按新授权重验，不能激活或沿用旧事实。激活、到期和撤销不改写原核验状态或时间，not_assessed/unknown也不因签收获得verified_at。该期限不机械套用到所有合成工程控制或永久账本。Live规格前置票必须建好受信接收机制，并对适用、仍有效的分项verified证据完成新的显式人工激活；不能以本票文档接收替代。

B/H及任何对外说明须保留分项边界；对应能力仍未证实时，不得宣称实际Pi300秒、供应商错误处置、实际参数效力或日期映射已经通过。doctor和日报须显式提示相应unknown，同时保留not_assessed或unknown的原状态、原因、证据时点及下一动作；不能用健康汇总或命令退出成功盖过缺口。证据三态不替换现有诊断四态。

代价是接收权威、用途能力集合、逐项失效依赖和用户输出都须维护同一分项模型；收益是有限事实可复核地保留，未测能力继续阻断其对应用途，签收和激活不会延长旧证据寿命。
