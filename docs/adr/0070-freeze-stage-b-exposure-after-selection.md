# 从选样授权起永久保留阶段 B 暴露依据

状态：已接受；日期：2026-11-14；依据：[所有者裁决 2](https://github.com/MeteoBoy4/PaperRadar/issues/185#issuecomment-6848385568)。补充 ADR-0036 的暴露边界，不改变 ADR-0030 的强身份与权威版本关系规则。

只在候选清单看过题名或摘要，不构成阶段 B 的已暴露论文。选样接受授权以及其后的持久事实构成暴露依据；选样历史、Screening／Read 请求或 attempt、人工决定、PDF 确认及附件、持久报告成员均进入历史并集。失败、尚未完成及后来被换下的样本永不从此集合删除。

将候选展示也排除会耗尽可用盲评样本；只排除成功链又会遗失已参与实验的失败样本。这个边界以持久事实而非 Agent 记忆定义，代价是选样后即使未执行模型，也永久承担正式校准排除。跨库依据使用规范 DOI 与权威版本关系，不依赖本库临时身份；旧结果仍只供实验回查，不提升为生产结果。

没有 attempt 的历史 Read 登记只证明论文级请求，不证明某一未经持久记录的精确元数据版本曾被发送。该依据关联冻结时已有的强 DOI 与权威版本关系，不按今日选择或墙钟推定历史版本，也不伪造回填。
