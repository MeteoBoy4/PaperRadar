# 以只追加的显式选择确定当前正文

状态：已接受；依据：[所有者补充裁决](https://github.com/MeteoBoy4/PaperRadar/issues/185#issuecomment-6879014360)；补充 ADR-0043 的正文选择依据与 ADR-0036 的实验隔离，既有永久否决和预算规则继续适用。

同一 PDF 可以因提取语义变化产生多个合法成功正文；仅以唯一成功确定当前正文会阻断修复后的材料核查。由所有者授权、Agent 代录只追加的显式正文选择，绑定实验根、当前论文版本与修订、冻结样本、明确 PDF 附件及哈希、已注册成功的准确正文三元组。持久顺序决定后继选择；新成功、当前配置和墙钟均不自动改选。没有有效选择时保留原来的单成功行为，多成功继续拒绝。

选择先于新正文的六项所有者核查，不授予 Read、普通生产消费、质量通过或执行许可。旧正文、旧核查及指纹永久否决保留；选择不创建或结算 attempt，不重置预算，不改变在途 Read 的历史依据。版本、修订、样本或 PDF 改变后旧绑定不能成为当前选择。代价是新增持久事实和迁移／恢复义务，并且必须由所有消费者共享 Body 的当前正文权威，而不能把 CLI 传入三元组直接视为选择。旧报告与暴露导出继续按各自冻结输入和原捕获范围回放。
