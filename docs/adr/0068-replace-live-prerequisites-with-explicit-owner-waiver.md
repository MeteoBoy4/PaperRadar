# 以所有者显式豁免取代 Live 证据作为产品执行前提；证据链转为可选后置

状态：已接受；依据：[#177 所有者永久降范围裁决](https://github.com/MeteoBoy4/PaperRadar/issues/177#issuecomment-6814413453)。取代 ADR-0047、0051、0052、0053、0055、0056 中“产品执行必须凭证据”的约束关系；补充 ADR-0050，主机级出站不再是产品执行的强制前提。其他历史、证据真实性和隔离约束保留。

## 背景与取舍

在单人项目中，Live 证明仪式、封印部署与反复现场恢复的成本超过其价值。所有者选择在产品内显式承担未取得准入证据的风险，永久将 Live 降为可选后置复验路径。保留证据链而取消强制前提，比继续扩大宿主部署范围更符合本项目边界；这不是将失败或未测重新解释为成功。

## 决定

Screening `run_attempt` 与 Read execution 支持所有者豁免。状态必须显式、持久、版本化，默认仍失败关闭；开启只由所有者显式动作产生，流水线不能静默开启。豁免记录与模型语义、批准计划、业务预算、Read evidence 分开。doctor 显示“证据前提已由所有者豁免（ADR-0068）”及受控原因码；原能力状态仍为原状态，未评估仍是 `not_assessed`，不制造 `verified`、`unknown` 或 test 来源资格。

豁免只移除执行证据前提：不要求已接收／激活的六格能力证据、受保护观察、nft 出站规则、placement/cgroup 放置或私有 resolver 视图。无放置时使用宿主 DNS，不创建 cgroup 放置。严格模式和可选证据链保持原有拒绝与来源核验。

不可豁免的边界包括 Landlock 文件隔离及 TCP 443 限制、`--no-session`、子进程软硬 `RLIMIT_CORE=0`、`no_new_privs`、宿主认证 helper 分离、attempt 独占临时根、固定供给与受控调用、业务预算／attempt／配额、输出权威接收与正式消费者拒绝 test 来源。真实资料外发确认、B 实验根、逐文档质量与最小日报仍独立成立。

主机 root 部署由所有者亲自卸载：五入口、sudoers、unit/slice、项目 nft 规则、resolver 视图及 runtime 退出当前执行。卸载须核对现有身份、保留原字节归档，不加载新 AppArmor 策略，不改 journal。账本、inbox、intents、归档、失败和停止历史、v22–v24 候选原字节全部保留。零认证／零联网／零模型与 40/40 未动按原事实记录，不重置或另建累计域。本裁决不要求新的封印包。

## 代价与恢复

豁免下无主机级出站强制，DNS 使用宿主 stub，无 Live 溯源保证；Landlock 不限制 UDP/DNS，也不证明供应商端点、认证刷新、RPC 或模型参数行为已经验证。未验证能力继续披露，不以 doctor 成功或业务成功替代证据。

将来恢复证据链须由所有者关闭豁免，恢复所需受保护部署，并在新边界后重新批准采集、接收及显式激活；旧激活不得复活。原账本、回执、历史向量和失败事实保持各自原有含义与有效期。恢复不能延长旧授权窗口、重置额度或改写业务事实。

Live 的完成判据是豁免落地与文档同步；原六格及部署机复验判据由可选证据链承接，不再阻塞 B。B 仍按自身入口与质量闸门验收。
