# 论文版本身份与来源观察仲裁

状态：已接受语义；#69–#74 已落地身份、Feed、四源仲裁、版本关系、输入映射及组合隔离恢复，#75 注册独立 A6 验收。依 [#67](https://github.com/MeteoBoy4/PaperRadar/issues/67) 用户 D1–D4 与 N1/N2 裁决，DOI 与版本一对一，Feed 回摆仅推进 last_seen，强身份冲突整笔拒绝业务事实，关系冲突保留观察/关系并等待合并。具体目标边界以 [论文事实 Contract](../contracts/paper-facts.md) 为准。

一个 DOI 恒绑定一个 Paper/Version，一个版本最多一个 DOI，preprint/journal 创建后不可变；online-first 到卷期只是同版本修订。不同 DOI 只有权威关系才归入同一 Paper，不能再以“同 DOI 多公开形态”发明版本键。该决策收窄 ADR-0001/0005 的 A6 路径而不实现两个既有 Paper 合并；暂存重复比错误合并安全。

Feed 同源仲裁只用不可变首次 observed_at，A→B→A 不回摆，last_seen 取最大且永不参与仲裁。代价是当前 Feed 文本可能落后于上游回摆，换来重放不会悄悄改写修订依据。publisher/注册机构另按来源流的候选贡献保留变化，不能套用 Feed 字节去重。

强身份冲突拒绝发现、观察、候选等全部业务行，最多留下完整未引用来源快照；关系冲突保存观察及关系，新版本不能唯一归属时独立建 Paper，返回成功 requires_merge，关系生效由两端归属派生。这维持 ADR-0005 的保守身份原则。相对于 ADR-0017 的永久保留 Feed 目标，A6 推迟强冲突观察持久化仅因没有真实 Feed、只有离线测试调用，当前丢失窗口为空。**阶段 C 真实 Feed 接入前必须补齐强冲突观察持久化，此前适配器不得直接复用 A6 拒绝路径。**

来源观察、字段候选和版本修订是不同事实；修订只保存完整逐字段候选引用，不复制摘要。采用文本规范形式 v1（行尾 LF、去外围空白）、历史重建与显式 BEGIN 一致读视图；不把题名摘要叫 Docling 正文，不保存 StageInput。事实只追加，无保留期、孤立 blob 清理或修订压缩，增长成本留给单独策略票。

## #69 取得事实的后续用户裁决

[用户选择轻量重复取得事件](https://github.com/MeteoBoy4/PaperRadar/issues/67#issuecomment-6333258795)，覆盖 #67/#71 先前“候选无贡献不写业务行”的默认，A6 未发布的 v1 据此完善；既有 A1–A5 不变。publisher 的有效取得均保存不可变稳定请求键和原结果，相同候选复用旧观察/候选，新的取得时间参与获选 provenance；not_retained 表示未新增来源材料/候选正文，仍可能保存轻量取得与引用式修订。新响应只保留 SHA-256 时必须明示未保留全文，不为非业务变化永久发布新大包。空候选的回执不依赖未来论文身份，日后建 Paper 不重新解释旧结果。Feed 的首次时间与 D3 回摆规则保持不变。当前 URL 形式的来源定位元数据拒绝 userinfo/query/fragment，opaque 查询键不猜敏感参数，这不是 Feed URL 的规范化规则。

## #69 同材料重新解释的最终用户裁决

[用户选择完整新解释](https://github.com/MeteoBoy4/PaperRadar/issues/67#issuecomment-6334252628)：更高 parser_version 的有效非空解释整体替换同材料旧解释，旧解释缺项不再回填，其他有效材料/来源仍可补缺；不同 payload 继续缺项不清空。全空 v2 保留 not_retained 保护，不替换规范字段、不制造清空修订。每个有效输入必须显式声明完整解释；同流同材料版本单调，同版本解析内容恒定，旧请求精确重试优先保持原结果。服务不能根据字段减少识别真实解析器是否撒谎；阶段 C 每次 parser 升级前必须以固定样本回归并声明关键字段减少，承担实际真实性与成本门禁。本裁决覆盖先前关于空解释清空、无身份空解释派生影响的未实施讨论；Feed D3保持原义。


## #70 Feed 发现实现

Feed 身份只在数据库按规范 URL 唯一登记；HTTP(S) 的 scheme/host 只折 ASCII 大小写，默认端口移除，
原样 path/query 与尾斜杠保留，userinfo/fragment 拒绝。原文指纹即单 item 全部提交字节的 blob SHA-256，
明确单 item 声明与可识别文档/多 item 包装检查不构成生产 XML 真实性审计。
连续无 DOI 版本、唯一补 DOI 入口、同 DOI 跨 Feed、强冲突整笔拒绝沿用 D1/D4。
Feed 字段使用与出版者相同的纯仲裁和引用修订权威，出版者有效非空字段优先，Feed 补缺；
跨流 parser 序列隔离，稳定 tie-break 使用规范 URL/entry ID，不用随机 UUID。
D3 回摆时仅更新 last_seen，既有原文解释的首次时间保持不变；完整高版本解释替换与全空保护沿用最新裁决。

a602 在同一事务暂存并重建 source_kind 约束的完整依赖闭包，保持非空 a601 事实及外键，
新增 Feed 身份/连续条目/发现/解释引用；不改 a601。取得事实新增 DOI 原书写，历史未知值保持 NULL，
不伪造历史、不进入规范身份或 StageInput。备份固定副本同时校验 Feed 原文、完整解释和历史归属。
本票没有真实 Feed 或解析器；阶段 C 强冲突观察持久化与 parser 升级固定样本回归仍是硬门禁。


## #71 来源仲裁与人工字段修正实现

四类来源共用同一纯仲裁规则与完整候选引用式修订。非人工依来源优先级、observed_at、payload hash、
parser_version、稳定流键排序；最高解释由来源流和材料隔离。人工修正绑定版本内显式请求身份，
使用 BEGIN IMMEDIATE 原子追加的取得 event_no 选择最新人工事件；该号不参与非人工排序。
人工完整请求字节保存在来源制品，审计引用另存 actor/reason/request_id，显式核验和备份对照请求原文，
防止仅外层哈希正确的审计篡改。actor/reason 未认证，无产品写 CLI 或撤销。

公共当前与历史读取统一到调用方固定读事务的 resolve_revision；返回完整规范字段、provenance、
可空的该版本真实选择依据。历史入口不是 as-of 当前查询，不用 selected_at/revised_at 推断事务内顺序。
后续关系/正式映射继续扩展该读面，不自行拼接多个连接。a603 原子保留并扩展 a602 的完整依赖闭包。
纯文本规则、共享读校验和候选读取下沉，消除 feed/text 与 feed_queries/queries 的循环导入。


## #72 权威关系与当前选择实现

规范关系以预印本 DOI/正式版 DOI 全局唯一，所有来源和反向别名的原始断言追加引用同一事实，
保留原始端点书写、类别与 locator；新增关系与字段一起判贡献。关系与版本登记分离，
relation-only 不制造空版本。关系没有撤销或 active 位，三态仅从已有端点归属派生。
新 publisher/registry/Feed 版本查询全部保留关系，以既有 Paper 集合唯一性归属；
歧义时独立建 Paper 并成功返回 requires_merge，不移动任何已有版本。
这避免把权威关系等同既有 Paper 合并，代价是有些已存在的重复 Paper 只能等待未来人工 merge。

选择按明确事件序号只追加 initial/journal_upgrade，同级保持原选；正式版缺摘要也升级，
人工字段仍绑定原版本。历史读面保持真实请求版本的可空 selection，无 as-of 时钟推断。
a604 只追加关系/引用、选择序列与原回执原因，a601–a603 不变。
注册机构只有关系路径可省略既有 target，普通 registry 首次身份入口仍拒绝；显式目标的强冲突整笔拒绝。
关系来源真实性、真实 Crossref 双向供给、parser 升级完整性与阶段 C 强冲突材料保存仍未 live 验证。


关系材料纳入来源取得的公开 response_bytes_retained：该次响应作为字段或关系材料登记即为 true，
内容寻址去重不使其变 false。字段观察创建依据独立匹配不可变材料请求，关系材料依据独立核对创建取得与制品，
不再借这一公开标志推断字段观察创建者。relation-only 的未绑定取得通过关系 assertions 公开同一标志及真实制品引用；
无新材料的轻量重复仍为 false，精确重试保持原回执。


## #75 独立结论接入

在既有同次 run/receipt/publication/terminal/status 协议登记必需 A6，前置 A1、完整 A2、A3、A5，
不增加 A4 业务依赖。生产 Feed 纯规则公开格式版本 1，原始单 item SHA-256 字节算法保持不变；
固定能力用例/材料与正文裁决归属见 A6 验收文档。历史 A5 未覆盖论文映射的结论不回写。
本地闭环不验证真实来源、parser 完整性或阶段 C 两项门禁，不等于完整阶段 A/live。
