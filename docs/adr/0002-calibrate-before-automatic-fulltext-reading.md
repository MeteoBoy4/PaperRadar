# 校准通过后才启用自动全文精读

PaperRadar 在总计 32 篇、每个首发期刊至少 4 篇的盲评校准完成前，将 Screening Agent 的研究边界判断、摘要层价值预测和可选复用升级保存下来，并由版本化规则确定性地产生筛选建议；用户依据同一冻结输入独立判断。样本从未暴露 Agent 建议且没有既有人工筛选决定的合格 Feed 论文中，按元数据就绪时间和持久四刊轮转机械选取；阶段 B、预热和其他排除都计数披露。批次最多五篇，上一批未全部盲评并揭晓时不能创建下一批。正式校准前先用用户手工选择、明确标为不计指标的 10–20 篇预热样本调整配置；随后冻结 Screening 与 reuse-assessment 模型、提示词、Profile、契约、升级参数和规则。Read 模型不属于校准输入，只需在运行 Read 前明确配置；所有模型都禁止自动 fallback。

只有系统建议 `accepted` 的精确率达到 80%，用户认为 `accepted` 的论文至少 90% 没有被系统判为 `denied`，系统作出 `accepted` 或 `denied` 的论文至少达到 16 篇，系统与人工各自至少给出 5 个 `accepted`，用户才可显式启用自动全文精读。所有界面展示原始分子/分母、人工 pending 及其不对称计数方式；任一 accepted 分母为 5–9 时给出不阻塞门禁的 `small_sample`，少于 5 时结论为“不确定”，并按四刊各增加 2 篇的平衡目标继续。界面还对照隐含接受率与 3/20 自动容量，但只披露预计积压，不把容量变成新的质量门槛。Read Agent 的人工抽查结果单独记录，不构成启用门禁。

若前两项比例门槛失败，第一版允许根据揭晓结果调优后复用同一组人工标签重算；这种 calibration evaluation 必须保存各轮运行组合和指标，并显式标为复用了已揭晓标签、不是新样本独立验证。可能改变 Screening 语义或建议边界的变化先暂停自动精读，由用户附理由分为 minor 或 major：minor 继承门禁并只在既定未决范围内按指纹重算，major 关闭门禁，直到同标签重算或新校准通过且用户针对新 evaluation 再次显式启用。系统只提示差异与风险，不能自行决定等级或静默恢复旧 enable。
