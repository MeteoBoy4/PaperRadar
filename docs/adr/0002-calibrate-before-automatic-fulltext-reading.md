# 校准通过后才启用自动全文精读

PaperRadar 在四个首发期刊各自连续选取 8 篇、共 32 篇论文的盲评校准完成前，将 Screening Agent 的研究边界判断与价值预测保存下来，并由版本化规则确定性地产生筛选建议；用户对相同题名和摘要作出的独立判断形成生效的筛选决定。校准按最多五篇、四刊轮转的固定批次推进，上一批未全部盲评并揭晓时不能创建下一批，但不要求用户按连续日历日处理。开始校准前必须明确并冻结一个 Screening 模型和一个 Read 模型，运行配置缺少其中任何一个时不得开始；系统不会自动 fallback。

只有系统建议 `accepted` 的精确率达到 80%，用户认为 `accepted` 的论文至少 90% 没有被系统判为 `denied`，系统作出 `accepted` 或 `denied` 的论文至少达到 16 篇，且系统至少给出 5 个 `accepted`，用户才可显式启用自动全文精读。系统 accepted 的最小分母仍接受 5；所有校准界面必须展示原始分子/分母，5–9 时给出不阻塞门禁的 `small_sample` 警告。后两个门槛防止筛选器通过把几乎所有论文送入 `pending` 来规避判断；若分母不足，校准结论是“不确定”而不是失败，此后按四刊各 2 篇的连续平衡批次继续。Read Agent 的人工抽查结果单独记录，但不构成启用门禁。启用后人工决定仍具有最高优先级。这个门禁增加了启动期人工工作和独立的建议记录，但避免未经验证的筛选器制造高成本、低价值的全文精读结果。

若前两项门槛失败，第一版允许根据揭晓结果调优后复用同一组人工标签重算；这种 calibration evaluation 必须保存各轮运行组合和指标，并显式标为复用了已揭晓标签、不是新样本独立验证。可能改变 Screening 语义或建议边界的变化先暂停自动精读，由用户附理由分为 minor 或 major：minor 继承既有门禁但仍按输入指纹重算受影响制品，major 关闭门禁，直到同标签重算或新校准通过且用户针对新 evaluation 再次显式启用。系统只提示差异与风险，不能自行决定等级或静默恢复旧 enable。
