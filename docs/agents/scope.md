# V1 范围

## 失败成本顺序

权衡产品行为时按此排序（ADR-0021）：

`attention_overload > missed_relevant > wasted_full_read > review_backlog`

## 获取边界

摘要与全文的获取按 ADR-0032 的两分边界判断：不看工具，而看请求是否试图改变来源对自己身份、权限或频率的判断。

- 允许：如实标识的正常请求头、受控浏览器渲染公开页面、出版者官方 API（含 Wiley TDM）、合法补充渠道（Crossref/DataCite/Unpaywall/OpenAlex/开放仓储），按站点规则的频率、超时与退避。
- 审慎允许（默认关闭、用户显式启用、凭据隔离、单篇按需）：本人合法持有的机构账号、登录会话与订阅权限。
- 禁止：破解验证码、伪造浏览器或 TLS 指纹、轮换代理逃避封禁或限流、绕过付费墙及其他明确访问控制、未授权批量下载受限全文。

获取策略是版本化事实，不同策略的取得结果分开保留。默认值可按四刊真实审计结果在新 Issue 中调整，但不得为了结果好看改变固定样本选择或改写既有审计结论。

## V2 能力

以下能力属于 V2，只在任务明确要求时实现：

- Web、桌面或移动端 UI。
- OCR 或多模态文档理解。
- 模型或 Provider 自动 fallback（ADR-0004）。
- 基于引用量的排序或综合 Rank（ADR-0013）。
- Embedding、向量检索或主动关键词搜索。
- 超过一层的递归参考文献扩展。
- PostgreSQL、远程 API、多用户或权限系统。
