# 重构

## 模块设计

- 每个模块职责单一、依赖扁平，下层模块不 import 上层，模块间无循环依赖。目标：Agent 只读单个模块即可完成该模块内的工作。
- 目录结构反映功能分布：Agent 只看目录和模块划分，就能定位功能所在，不必通读代码。

## 重构任务

用户明确把任务定为重构时，按上述原则主动拆分文件、整理目录、调整模块边界，范围不限于单个模块。

完成标准：

- 外部行为不变，`./scripts/check-offline` 返回 0。
- Frozen Contract、已登记的版本和 Stage fingerprint 语义不变，不新增数据库 migration。需要改动其中任何一项时，任务已超出纯重构，先问用户。
- 文件移动与逻辑修改分在不同 commit。
