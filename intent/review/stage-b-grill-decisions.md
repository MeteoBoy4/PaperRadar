# 阶段 B grill 裁决归档

日期：2026-11-12。出处：所有者在本轮 `grill-with-docs` 中提供的材料、授权、要求及后续裁决。本记录保存一次性准备与裁决背景；目标以[规格 §11 B](../draft.md#阶段-bjgr-feed-第一条真实纵向闭环)为准，状态以[路线图 B](../../docs/roadmap.md#module-b)为准。

## 已定事项

- 所有者已指定仓库外独立实验根，真实 Research Profile 位于其 `config/profiles`。精确位置、联系邮箱与运行准备清单仅记在实验根的 `stage-b-preparation.md`；该私有清单是后续执行者的本机交接入口。
- Screening 与 Read 均使用所有者指定的 ChatGPT 订阅模型、各自的推理档位和 `provider_default`；OAuth 据所有者说明已认证。精确选择见私有清单，实际可用性仍由执行预检核实，不能从本轮配置检查推定。
- 所有者同意阶段 B 将研究偏好、论文摘要、合法取得的全文解析内容发送到指定外部模型；本阶段范围内模型调用、联网、脱敏数据与论文外发无需再次征求授权。每任务／阶段既有两次 attempt 预算、隔离及输出接收规则保持。该授权不延伸到后续阶段或任意外部目标。
- 启用 ADR-0068 的所有者显式豁免，由 Agent 依据本次授权执行并保留持久记录；豁免本身不代表 Live 能力已验证。
- 联系邮箱、测试论文已由所有者准备；样本仍须来自当轮 JGR Feed，PDF 在选样后由用户手动提供。单个进程内存上限为 8 GB。
- Agent 规划实验根内数据库、PDF、配置、模型结果、证据、日报、备份和独立恢复位置；真实 Profile、派生主题、OAuth 凭据、全文、模型原始响应及证据内容不得进入公开 GitHub 仓库。凭据继续使用独立认证边界，不进入数据库、日志、报告或普通业务备份。
- 人工选样前展示当轮 JGR 候选 Markdown 清单，包含原题名、摘要、DOI 和原文链接；支持按编号或 DOI 选择并保存理由。它是 Feed／元数据测试展示，不是最小日报，不受日报五项展示容量限制；缺失或受阻如实显示，不能编造完整摘要或将未就绪条目送入 Screening。
- 首张真实任务票的交付必须在首次 Screening 执行前完成，含规格既有 failures/retry、trace、中文 help／退出码与恢复要求。
- 用户选样即代表接受，Agent 在满足 Screening 成功依据后代执行接受，不再二次询问；取舍与安全边界见 [ADR-0069](../../docs/adr/0069-treat-stage-b-selection-as-owner-acceptance.md)。
- 所有者明确委托 Agent 根据真实 Profile 生成少量主题并用于 B 验证主题归类；不采用空主题集。生成的版本化材料只留实验根。本次授权限于 B 准备，不允许运行中的模型自行增改主题，不自动成为正式校准主题。
- 必须由用户参与的选样／换样与理由、合法 PDF 及版本归属确认、六项人工版式核查集中成简短可操作交互；Agent 准备直观材料并代执行已授权动作，其余工程工作自动推进，不要求用户阅读工程日志。

## 核查与结论

真实 Profile 的权威 Schema 验证通过，六段均配置；用户材料中原缺少 topics，而现有 value 就绪条件要求已配置主题集合。本轮已通过显式委托解决该选择。配置验证不证明研究内容正确、认证可用或模型运行成功。

当前没有阻塞 B 规格化的用户侧未决事项，本轮 grill 结束。DEC-1（四刊摘要稳定判据）和 DEC-3（附加摘要区块）仍按路线图由后续阶段承接。若实际样本超长、out_of_scope、缺摘要或无法通过质量门槛，按既有规则报告具体材料与下一动作；不预先把假设性故障转为新的用户决策。

本轮仅归档需求与准备资料，不交付 B 产品执行入口，不启用豁免、不调用模型或运行真实论文链。Contract 和 README 继续描述已实现能力；B 的实施与真实验收由后续规格／任务承接。
